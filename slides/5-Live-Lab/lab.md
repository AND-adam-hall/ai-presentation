### Station 1: The Prompt Desk
- Mastering the **Precision Stack**
- Stability Testing & Few-Shot Learning

Note: Use the four layers (Persona, Task, Context, Output). Your goal: Create a "Master Prompt" for a repetitive task. If the output varies wildly, run a "Stability Test" and add constraints. Provide 2-3 examples (Few-Shot Learning) to match the pattern.

### Station 2: Audio & Data

- Low-Code Dashboards with Gemini

Note:

### Station 3: Visual Assets

Note: 
- Creative: Prompt for mobile dashboards using specific styles.
