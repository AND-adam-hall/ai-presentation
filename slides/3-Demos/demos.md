# Art of the Prompt<!--.element: class="r-fit-text" -->
### Introduction to the Precision Stack

Note: Prompting isn't just "talking" to the machine; it's engineering a set of constraints to ensure reliable output. We use the "Precision Stack" to move from vague requests to high-fidelity results.

---
### The PCTO Model (The Precision Stack)
- **P**ersona (Who are you?)
- **C**ontext (What is the background?)
- **T**ask (What exactly do I want?)
- **O**utput (What format should it be?)

Note: 
1. Persona: Establish expertise (e.g., "You are a Senior Editor").
2. Context: Define boundaries and audience—avoid "The Kitchen Sink" (irrelevant info).
3. Task: Be specific about the "Job to be Done."
4. Output: Define the exact deliverable (e.g., "A Markdown table").
Best Practice: Use "Few-Shot Learning" by providing 2-3 examples of good output. If results vary wildly, your prompt is under-constrained.
